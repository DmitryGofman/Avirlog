How it stays within Apple's rules. A Live Activity is meant for a live, time-bound event with a clear start and end — a countdown to “log your breath in the next 10 minutes” fits exactly. Its Left/Right/Both buttons use App Intents (iOS 17+), so a tap logs instantly with no long-press and without opening the app. When the window closes, the Live Activity ends (as required) and a normal reminder takes over — long-press there for the same buttons. Set a 30-min reminder → a 10-min live window, then quiet until the next one. This is native (ActivityKit + WidgetKit), so it's a build-on-device step — the same foundation as the widget.
Drag any slider to see the connected-vessels mechanic. Colours: Ida green = left, Pingala terracotta = right. Whatever you log stores as a blend and still resolves to Left / Right / Both (near 50/50 = Sushumna) for every existing view.
